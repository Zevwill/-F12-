# 国创赛·挑战杯创新创业项目网络评审自动化截图工具
针对项目网络评审打印和F12扒拉不下来源PDF数据流时用的自动化截图工具
> 小罗开发 | 自动翻页截图，一键导出PPT

## 你是否遇到过这样的场景？

- 网络项目评审时，系统锁定了 `Ctrl+P`，**打印功能用不了**
- 想用 `F12` 抓图，结果全是碎片化的切片，拼都拼不起来
- 网页课件内容很好，想保存下来学习，但手动一张张截图太累
- 有些平台根本没有下载按钮，内容过了就看不到了

**遇到好的东西就应该保存学习。** 这个工具就是帮你高效完成这件事——框选区域，自动检测翻页，一键导出PPT。

## 功能特性

| 功能 | 说明 |
|------|------|
| 框选截图区域 | 鼠标拖拽框选网页/课件的任意区域 |
| 自动翻页检测 | 画面变化自动截图，20ms检测 + 50ms冷却，快速刷页不漏截 |
| 手动补截 | `F9` 键随时手动截一张 |
| 一键导出PPT | `F10` 键导出为 `.pptx` 文件，PowerPoint直接打开 |
| 清空重来 | 换项目时一键清空截图，不用重启软件 |
| 收款码放大 | 点击收款码可查看原图 |
| 全局快捷键 | `F9` 截图 / `F10` 导出，任何窗口下都能用 |
| 单文件EXE | 不需要安装Python，双击即用 |

## 使用方法

1. 双击 `课件截图工具V11.0.exe` 启动
2. 按住鼠标左键拖拽，框选课件/网页的显示区域
3. 点击 **开始**，工具自动检测画面变化并截图
4. 翻页完成后点击 **导出PPT**，选择保存位置
5. 生成的 `.pptx` 文件用 PowerPoint 打开即可

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `F9` | 手动截一张图 |
| `F10` | 导出PPT |
| `Esc` | 取消选区 |

## 界面按钮

| 按钮 | 功能 |
|------|------|
| 开始/暂停 | 启动或暂停自动截图 |
| 补截 | 手动截取当前画面 |
| 导出PPT | 将所有截图导出为PPT文件 |
| 清空 | 清除所有截图，重新开始（保留选区） |
| 重选 | 重新选择截图区域 |
| 退出 | 关闭程序 |

## 适用场景

- **网络项目评审**：平台锁定打印和F12时，用截图方式保存课件内容
- **在线课程学习**：自动截取课件翻页，整理成PPT方便复习
- **网页内容归档**：需要保存的网页内容，截图整理成文档
- **演示录制辅助**：记录操作步骤截图

## 技术说明

- Python + PyQt5 图形界面
- mss 高速屏幕截图
- numpy 像素差异检测（阈值5%）
- python-pptx 生成标准PPTX文件
- pynput 全局快捷键监听
- PyInstaller 打包为单文件EXE

## 项目结构

```
course_capture_v11/
├── course_capture_v11.py    # 主程序源码

```

## 从源码运行

```bash
pip install PyQt5 mss numpy Pillow python-pptx pynput
python course_capture_v11.py
```

## 打包为EXE

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "课件截图工具V11.0" --add-data "logo.png;." --add-data "wechat.jpg;." course_capture_v11.py
```
